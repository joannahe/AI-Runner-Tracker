Connect your Garmin data

For a local import of your own activities, use a Garmin Personal API Key. Review before saving.

  1. Create your Personal API Key in Garmin Connect. Open Garmin Connect ↗ Sign in, create a key, and copy it when shown.
  2. Paste the key into this local page. It is used once and never saved to the project or database.
  3. Choose dates and preview. Confirm only after checking the activity count.

A Personal API Key accesses only its owner's Garmin account. This import reads activity summaries for the selected dates, not sleep, routes, or FIT files.

Choose up to 31 days per import. Repeat for older periods.

Other ways to import

You can use a Garmin Connect Activities CSV instead. Connecting multiple people's accounts requires a separate Garmin Developer Program app.
